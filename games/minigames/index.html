Eleven games.
One more go.

Quick challenges for memory, reflexes, pattern recognition, and a little bit of luck. Pick a game, press play, and see how you do.

11 EXPERIMENTS / BUILD 003
GAME 01KNOWLEDGE

Pokémon or Medicine?

Six names. Three Pokémon and three medicines. Select the Pokémon to score two points each.

GAME 02REFLEX

Freeze Frame

A marker races along the numbers 1–2–3–4–5–4–3–2–1. Freeze it and score the number underneath.

GAME 03MEMORY

Remember the Pattern

Watch ten flashes across a 3 × 3 grid, then repeat the exact sequence. One mistake ends the run.

GAME 04MATHS

Ten-Second Maths

Choose addition or multiplication. Answer as many questions as possible in ten seconds total.

GAME 05OBSERVATION

Odd One Out

Find as many odd ones out as you can in 15 seconds. Wrong answers don't count against you.

GAME 06PREDICTION

Higher or Lower

Predict whether the next card in a shuffled deck will be higher or lower. One wrong guess ends the game.

GAME 07FOCUS

Color Clash

Ignore the word. Choose the color of the ink it's written in. A 15-second total color challenge.

GAME 08QUICK COUNT

Quick Count

Count the symbols. Quantities increase each round. You have 60 seconds total; one wrong answer ends the game.

GAME 09MEMORY

Memory Match

Find matching pairs of symbols in a 4 × 4 grid. Clear all eight pairs.

GAME 10SPEED

Target Tap

Hit as many targets as you can in ten seconds. The target moves after every hit.

GAME 11REFLEX

Circle Freeze

A marker continuously loops around a circle through +5 to −5. Freeze it on a number to score.
