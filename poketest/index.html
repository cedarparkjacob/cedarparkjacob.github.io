REFERENCE IMPLEMENTATION

How /poke loads its cards

01 · DATA

Prebuilt JSON catalog

./data/cards.json

/poke fetches a catalog that was assembled before the page loads. It receives ready-to-use card records and set records in one JSON file.

02 · ARTWORK

Separate image host

raw.githubusercontent.com/Vociferix/ptcgp-images/

Each card record contains an image filename. The app adds that filename to a fixed image base URL.

03 · DISPLAY

Shared card component

.card → .card-image → img

The card tile uses a 3:4 image area, object-fit: contain, and the same card metadata layout. These tests reuse those visual classes.

What we are comparing

Data availability, image URL reliability, language coverage, load speed, and whether the returned records contain the fields needed for expansion, rarity, artist, type, and Pokédex filters.
