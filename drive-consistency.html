What this test can establish

INTERPRETATION
Same structure Structure changed Request or scan error

A changed result between checks shows when this API key and browser first observed a different tree. An unchanged result does not prove Drive has no internal pending work; it means the API returned the same visible structure. A 403/429/5xx response, CORS failure, or pagination error is recorded separately. Browser CORS rules can hide some response headers or error bodies, and this page cannot inspect Google's internal indexing state.
