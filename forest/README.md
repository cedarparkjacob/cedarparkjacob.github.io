# Forest — a procedural exploration world

This project is an adaptation in progress of [Abyssal Garden](https://github.com/Noniv/abyssal-garden) by Maksymilian Dendura.

The original project is MIT-licensed. Its copyright and license notice are preserved in `LICENSE`. The original source architecture and WebGPU renderer are being adapted from an underwater environment into a free-roaming forest.

## Development

The original build system uses Node.js 18+:

```bash
cd source
npm install
npm run build
```

The forest adaptation is currently in progress. The intended experience uses free-roaming, three-dimensional gliding movement rather than ground-based walking.
